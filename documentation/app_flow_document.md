# App Flow Document

## Onboarding and Sign-In/Sign-Up
A new user begins their journey by visiting the web application’s landing page. On this page, they can read a short introduction about the cognitive training platform and click a sign up button to get started. The sign up process asks the user to enter their email address and choose a secure password. After the password, the user is prompted to provide a username, select an age range, and set basic training goals so that the system can personalize exercises. Once they submit this information, the app sends a verification link to the provided email. The user confirms their address by clicking that link, and then they are automatically redirected to the sign in page. Signing in requires entering the verified email and password, and from here the user is taken to the main dashboard. If the user ever forgets their password, they can click a “Forgot Password” link on the sign in page, enter their email address, and receive a reset link. Clicking the reset link brings them to a secure form where they choose a new password before returning to the sign in screen and logging in. At any time after logging in, the user can find a “Sign Out” option in the top header or sidebar which immediately ends the session and returns them to the landing page.

## Main Dashboard or Home Page
After successfully signing in, the user lands on the main dashboard. Along the left side of the screen there is a vertical navigation bar showing links labeled Training Modules, Progress, Settings, and a Sign Out option at the bottom. Across the top of the page is a header bar that displays the user’s avatar or initials, and clicking that reveals quick access to profile details and sign out. The center area of the dashboard features a friendly welcome message with the user’s name, followed by three summary cards that highlight today’s recommended exercise, the current streak count of consecutive training days, and the total points accumulated so far. From this home view the user can click on any summary card or navigate via the sidebar to immediately enter a training session or check progress charts.

## Detailed Feature Flows and Page Transitions
When a user selects Training Modules from the sidebar, they are taken to a page listing available exercise categories such as Memory, Logic, and Pattern Recognition. Each category is represented by a card or tile. Clicking on a category takes the user to the first exercise in that module. The exercise page shows clear instructions, a countdown timer, and the interactive challenge itself. The user completes the task by interacting with on-screen elements and then submits their answers. The adaptive engine evaluates performance instantly, adjusts the next exercise’s difficulty, and awards points. A brief results screen appears with feedback on accuracy, time taken, points earned, and a prompt to Continue or Return to Dashboard. Choosing Continue begins the next exercise in the sequence. If the user navigates back to the Training Modules page, they see the current module’s progress indicator so they can pick up where they left off.

Clicking Progress in the sidebar transports the user to a page displaying visual charts and statistics. The top section shows a line chart of accuracy over time, with interactive date filters. Below that is a bar graph of average completion speed per session and a section detailing badges earned and milestone achievements. Users can click on any badge icon to see when it was unlocked. A back link in the header returns users to the main dashboard.

If the user has administrative access or beta features enabled, an additional link appears in the sidebar labeled Admin Panel. Selecting that reveals management tools for reviewing user feedback, adjusting exercise content, or configuring difficulty parameters. Navigating away from that panel always includes a Save and Return button to bring the user back to the dashboard flow.

## Settings and Account Management
The Settings page is accessible from the sidebar or by clicking the profile avatar in the header. On this page, users find a section for Personal Information where they can update their username, email, age range, and training goals. A separate area allows them to change their password by entering the current password and choosing a new one. Below this, there is a Notification Preferences section where the user can opt in or out of daily reminder emails or progress summaries. Although billing and subscription features are planned for future releases, version 1.0 does not include any payment or subscription settings. A Save Changes button commits any edits, and a Cancel link or the Back arrow in the header returns the user to the main dashboard without saving.

## Error States and Alternate Paths
If a user submits an invalid email or password on the sign in page, a clear error message appears below the input fields prompting them to try again or reset the password. During password recovery, entering an unregistered email shows an alert that no account matches the address. If the reset link has expired or is invalid, the user sees a message explaining the issue and a button to request a new link. While completing exercises, loss of internet connectivity triggers a banner at the top indicating offline status and disables new exercise submissions until connection is restored. If the session times out due to inactivity, any click prompts the user to sign in again before continuing. Attempting to access protected pages such as Training Modules or Progress without signing in redirects the visitor back to the login page with a notice that authentication is required.

## Conclusion and Overall App Journey
In summary, a user’s path begins by signing up with an email and basic profile details, verifying their account, and then signing in to access a welcoming dashboard. From the dashboard they embark on interactive brain exercises organized by category, with the difficulty adapting in real time and points awarded for every completion. They can review progress through charts and badges, and they have control over profile settings and notifications. Throughout this journey, helpful error messages guide them back on track if something goes wrong. The typical end goal is to return daily to complete exercises, build streaks, monitor improvement over time, and earn rewards that encourage continued cognitive training.
